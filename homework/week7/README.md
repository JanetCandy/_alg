# 演算法作業：組合數 $C(n, k)$ 計算問題

## 一、 問題描述
在組合數學中，從 $n$ 個相異元素中取出 $k$ 個元素的方法數以 $C(n, k)$（或 $\binom{n}{k}$）表示。
其數學遞迴關係式（巴斯卡恆等式）為：
$$C(n, k) = C(n-1, k-1) + C(n-1, k)$$
基本邊界條件為：
* 當 $k = 0$ 或 $k = n$ 時，$C(n, k) = 1$。
* 當 $k < 0$ 或 $k > n$ 時，$C(n, k) = 0$。

本作業分別透過 **動態規劃 (Dynamic Programming)** 與 **純遞迴 (Pure Recursion)** 兩種方法來實作並比較其效能。

---

## 二、 方法一：動態規劃 (Dynamic Programming)

### 1. 原理
動態規劃透過**由下而上（Bottom-Up）**的填表法，將子問題的解儲存於二維陣列中，避免重複計算。
* **狀態定義**：`dp[i][j]` 代表從 $i$ 個元素中取出 $j$ 個的組合數。
* **狀態轉移方程式**：
  $$dp[i][j] = dp[i-1][j-1] + dp[i-1][j]$$

### 2. 複雜度分析
* **時間複雜度**：$O(n \times k)$。透過巢狀迴圈填滿大小為 $(n+1) \times (k+1)$ 的表格，計算次數固定。
* **空間複雜度**：$O(n \times k)$。需要配置二維陣列儲存狀態。

---

## 三、 方法二：純遞迴 / 非動態規劃 (Pure Recursion)

### 1. 原理
純遞迴法直接根據數學定義展開，不使用任何額外的表格記憶已計算過的中間結果。每當呼叫函數時，會直接分岔成兩個子呼叫，形成類似二元樹的遞迴結構。

### 2. 複雜度分析
* **時間複雜度**：$O(2^n)$（指數級）。由於沒有記憶中間結果，相同的子問題會被重複計算非常多次。
* **空間複雜度**：$O(n)$。主要取決於遞迴呼叫堆疊（Call Stack）的最大深度。

---

## 四、 總結與比較

| 比較項目 | 動態規劃 (DP) | 純遞迴 (Pure Recursion) |
| :--- | :--- | :--- |
| **設計邏輯** | 由下而上（Bottom-Up）、填表法 | 由上而下（Top-Down）、直接依定義展開 |
| **時間複雜度** | **$O(n \times k)$** （多項式時間，極快） | **$O(2^n)$** （指數時間，n 稍大即超時） |
| **空間複雜度** | $O(n \times k)$ | **$O(n)$**（僅耗費系統堆疊空間） |
| **重複計算** | 無，每個狀態只計算並儲存一次 | 極嚴重，大量重複計算相同的子問題 |
| **適用場景** | 實際應用、輸入規模較大（如 $n$ 達數百） | 僅適合教學展示數學定義 |
