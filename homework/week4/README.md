要解決搜尋與最佳化問題，常用的通用方法之一是**迭代法（Iteration Method）**。透過定義初始狀態、過渡狀態函數（Step function）以及收斂或停止條件，重複更新狀態變數以逐步逼近問題的精確解或最佳解。

# 通用迭代框架之應用與說明 (Iterative Framework)

姓名：許尹榛  
學號：111310561  
這題我用 Gemini 幫忙寫，程式在 [iter_framework.py](iter_framework.py)。

## 做法
`iter_framework.py` 是一個用於執行數值迭代法的通用 Python 模組。該框架將演算法的**主控制迴圈**（包含最大迭代次數限制與容許誤差判定）與**特定問題的數學轉移公式**進行解耦。

實作時只需傳入：
1. **步進更新函數 ($g(x)$)**：定義下一代的狀態計算方式 $x_{k+1} = g(x_k)$。
2. **初始估計值 ($x_0$)**：演算法開始搜尋的起點。
3. **終止條件控制**：包含容許誤差 `tol` (Tolerance) 與最大允許迭代次數 `max_iter`。

當前後兩代狀態的變化量 $\vert{}x_{k+1} - x_k\vert{} < \text{tol}$ 時，系統判定已成功收斂並輸出結果。

## 執行結果
```

➤ 迭代過程與結果詳情:

目標問題: 求解 sqrt(25) 的數值解

精確結果: 5.00000000
絕對誤差: 0.00000000e+00
總迭代次數: 6 次
```

## 心得
迭代法能將複雜的非線性求解問題簡化為重複的單步計算，非常適合電腦執行。然而迭代法的收斂速度與是否發散極度依賴初始值 $x_0$ 的選擇與轉移函數的特性；設計一個具備良好收斂性與邊界檢查的通用框架，能大幅提升程式碼的複用性與開發效率。
