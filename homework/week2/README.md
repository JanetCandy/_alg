## 🔍 詳細推導過程

### 1. $T(n) = T(n-1) + 8$
* **展開法**：
  $$T(n) = T(n-1) + 8 = T(n-2) + 8 \times 2 = \dots = T(1) + 8(n-1)$$
  $$T(n) = 1 + 8n - 8 = 8n - 7$$
* **Big O**：$O(n)$

### 2. $T(n) = 2 T(n-1) + 9$
* **展開法**：
  $$T(n) = 2 T(n-1) + 9 = 2(2 T(n-2) + 9) + 9 = 4 T(n-2) + 2 \cdot 9 + 9$$
  $$T(n) = 2^{n-1} T(1) + 9 \sum_{i=0}^{n-2} 2^i = 2^{n-1} + 9(2^{n-1} - 1) = 10 \cdot 2^{n-1} - 9 = 5 \cdot 2^n - 9$$
* **Big O**：$O(2^n)$

### 3. $T(n) = 2 T(n/2) + 1$
* **假設 $n = 2^k$**：
  $$T(n) = 2 T(n/2) + 1 = 4 T(n/4) + 2 + 1 = \dots = 2^k T(1) + \sum_{i=0}^{k-1} 2^i$$
  $$T(n) = n \cdot 1 + (n - 1) = 2n - 1$$
* **Big O**：$O(n)$

### 4. $T(n) = T(n/2) + 1$
* **假設 $n = 2^k \implies k = \log_2 n$**：
  $$T(n) = T(n/2) + 1 = T(n/4) + 1 + 1 = \dots = T(1) + k$$
  $$T(n) = 1 + \log_2 n$$
* **Big O**：$O(\log n)$
